- 身份管理通过已有管理员 JWT 的 `/api/finance-agent/chat-bindings` 和已有财务 Agent 页面完成；真实数据库账号状态决定权限。旧版群绑定不自动升级；仅知主人微信号也不能获得管理员权限。
- 复用既有团队授权判断。成员只查本人；队长仅管理原授权团队；群内不返回收支金额、工资明细或执行写操作。

- 重算后只提交主人审核提醒。发布仅允许已绑定且有相应团队权限的主人确认，默认向有权限并开启提醒的成员提交各自明细私聊事项，不发公共群。
- 主动提醒有前缀、团队、月份、问题、真实页面链接和开关。交付统一出口后用 delivery_id 去重，发送前重新授权，回执区分 accepted / failed / uncertain；不把 accepted 当作已送达。缺少真实 BASE_URL 不生成占位提醒链接。
